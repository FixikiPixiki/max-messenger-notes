# Max Messenger Notes

Скрипт для консоли браузера, который добавляет приватные заметки к чатам в
веб-версии мессенджера [Max](https://max.ru/) — прямо поверх списка чатов,
без изменения самого приложения.
![alt text](image)
## Возможности

- 📝 Заметка на любой чат — свайп вправо по чату мышью или клик по тултипу
- 📌 Режим «всегда видны» — заметки закреплены рядом с чатами
- 💬 Режим «всплывающие» — заметка показывается по наведению/свайпу
- 📋 Список всех заметок с поиском по имени чата, редактированием и удалением
- 🔗 Заметка привязана к **имени чата**, а не к его позиции в списке — не
  теряется при сортировке
- 🔄 Необязательная синхронизация заметок между несколькими компьютерами
  (например, когда несколько сотрудников работают под одним аккаунтом)

## Установка

1. Откройте веб-версию Max в браузере и войдите в аккаунт.
2. Откройте консоль разработчика (F12 → вкладка Console).
3. Скопируйте содержимое [`dist/max-notes.js`](dist/max-notes.js), вставьте в
   консоль и нажмите Enter.
4. Готово — под списком чатов появится панель управления.

По умолчанию скрипт работает **только локально**: заметки хранятся в
`localStorage` этого браузера и не покидают компьютер.

## Синхронизация между компьютерами (по желанию)

Если несколько человек работают под одним аккаунтом на разных компьютерах и
хотите, чтобы заметки были видны везде — включите синхронизацию. Это
необязательно и требует небольшой дополнительной настройки один раз.

См. [`sync/README.md`](sync/README.md) — там сравнение двух готовых вариантов
и пошаговые инструкции для каждого. После настройки нужно вписать полученные
`SYNC_URL` и `SYNC_TOKEN` в начало `dist/max-notes.js` (несколько строк под
заголовком «НАСТРОЙКА СИНХРОНИЗАЦИИ») и заново вставить скрипт в консоль на
каждом компьютере.

> ⚠️ Если храните `dist/max-notes.js` со своими реальными `SYNC_URL`/`SYNC_TOKEN`
> в **публичном** репозитории — уберите их обратно перед коммитом, либо
> держите свою настроенную копию отдельно (не в гите).

## Команды в консоли

После установки скрипта доступны:

```js
showAllNotes()               // показать все заметки в консоли
clearAllNotes()               // удалить все заметки (с подтверждением)
addNoteByName("Имя чата", "текст") // добавить/заменить заметку по имени чата
```

## Ограничения

- Заметки привязаны к имени чата — если у вас несколько контактов с
  одинаковым именем, их заметки будут общими.
- Скрипт нужно вставлять в консоль заново при каждой перезагрузке страницы
  (браузер не сохраняет консольные скрипты между сессиями).
- Это неофициальный инструмент, использующий структуру DOM страницы Max —
  при обновлении интерфейса Max может потребоваться доработка селекторов.
